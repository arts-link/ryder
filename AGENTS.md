# AGENTS.md

Agent maintenance note for this repository:

- When the theme version receives a minor version bump or anything greater, refresh the Hugo themes submission screenshots in `images/screenshot.png` (1500x1000) and `images/tn.png` (900x600).
- `hugo_stats.json` (root and `exampleSite/`) is generated by `[build] writeStats` on every build and is **gitignored as of v0.3.0**. It used to be tracked, on the grounds that Tailwind clean builds depend on it; the cost outweighed that. Hugo rewrites it on every build, so simply running `hugo server` dirtied the working tree and aborted the next `git pull` — a recurring, silent-until-it-bites obstruction for anyone who built locally. Do not re-add it to git, and do not commit a regenerated copy.
  - **The one real consequence, measured rather than assumed:** on a *cold* clone with no prior build, the first `hugo --minify` produces CSS missing classes that exist only in the stats file — those assembled dynamically in a template rather than written literally. In this repo that is exactly 3 classes (`resp-sharing-button--small`, `resp-sharing-button__icon--solid`, `resp-sharing-button__icon--solidcircle`), out of 726. Every subsequent build has them, because the first build wrote the stats file. If you are producing a release artifact from a fresh clone, build twice.
- After code or template changes, run the full test/build checks before pushing: `npm test` and `hugo --source exampleSite --destination /tmp/ryder-check`. Do not rely on only targeted tests when broader changes were made.
