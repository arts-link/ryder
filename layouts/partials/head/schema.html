{{- /* Schema.org JSON-LD. Every block on this page is built as a Hugo `dict` and rendered with `jsonify`. That is deliberate and load-bearing: the previous version of this file hand-wrote JSON as template text, which meant a stray comment, a trailing comma, or an unquoted value produced a block that no consumer could parse — and nothing in the build ever said so. Structured data failing silently is the single worst failure mode in this file, so the format is now produced by a serializer rather than by careful typing. Rule for anyone editing this file: never write a `{`, a `"` or a `,` that is meant to reach the output. Build a dict, `merge` optional keys in with `with`, and hand it to `jsonify`. Emitted per page: • home — WebPage, plus the site-wide entity (see params.schema.type) • non-home — BlogPosting, plus a BreadcrumbList for the section path and, when the page has categories, a second one for the taxonomy path. To ADD types (MusicGroup, Event, Product, …) do NOT override this file — overriding it silently drops everything above. Use the no-op `head/schema-extra.html` hook instead, which is called right after this partial and shadows cleanly from a site's own layouts/. Config: [params.schema] type = "Organization" # or MusicGroup, Person, LocalBusiness, … */ -}} {{- $featured := partial "common-partials/opengraph/get-featured-image.html" . -}} {{- /* ── shared entity fragments ──────────────────────────────────────── */ -}} {{- $author := site.Params.author | default dict -}} {{- $authorName := $author.name | default site.Title -}} {{- $authorEmail := $author.email | default "" -}} {{- $logo := "" -}} {{- with site.Params.logo_png -}}{{- $logo = . | absURL -}}{{- end -}} {{- $person := dict "@type" "Person" "name" $authorName "url" site.BaseURL -}} {{- with $authorEmail -}}{{- $person = merge $person (dict "email" .) -}}{{- end -}} {{- $publisher := dict "@type" "Organization" "name" $authorName "url" site.BaseURL -}} {{- with $authorEmail -}}{{- $publisher = merge $publisher (dict "email" .) -}}{{- end -}} {{- with $logo -}}{{- $publisher = merge $publisher (dict "logo" .) -}}{{- end -}} {{- /* Keys every page-level block shares. */ -}} {{- $common := dict "isFamilyFriendly" true "copyrightHolder" $authorName "accountablePerson" $person "author" $person "creator" $person "publisher" $publisher -}} {{- with site.LanguageCode -}}{{- $common = merge $common (dict "inLanguage" .) -}}{{- end -}} {{- if not .PublishDate.IsZero -}} {{- $common = merge $common (dict "copyrightYear" (.PublishDate.Format "2006")) -}} {{- end -}} {{- with $featured -}}{{- $common = merge $common (dict "image" .Permalink) -}}{{- end -}} {{- /* ── page-level block ─────────────────────────────────────────────── */ -}} {{- /* .IsHome is the only homepage test used in this file.
